Component Name

Component Type

organism

Description

A high-conversion modal dialog used to upsell Premium subscriptions. It handles various contexts like feature locking, limit enforcement, and general settings upselling with support for loading, success, and error states.

Design System Alignment

Utilizes the specific 'Premium' amber/gold color palette defined in the design system to distinguish monetization flows from the primary application UI. Implements standard typography scales and spacing tokens.

Design Tokens Used

--color-premium-500
--color-premium-gradient
--radius-xl
--font-inter
--shadow-lg

Responsive Specifications

Mobile Adaptations

  • Behaves as a bottom sheet (anchored to bottom)
  • Full width with rounded top corners
  • Footer is sticky to bottom of viewport

Tablet Adaptations

  • Maintains modal dialog structure
  • Restricted max-width (480px) for readability

Desktop Enhancements

  • Center alignment overlay
  • Subtle drop shadows and entry animations

Accessibility Features

Keyboard Support

Focus trapped within modal, Esc to close

Screen Reader Support

Role='dialog', Aria-labelledby on title, Aria-describedby on benefits

Focus Management

Initial focus on subscription toggle or CTA

Aria Attributes

  • aria-modal='true'
  • aria-live='polite' for state changes

Color Contrast

Premium gold colors tested against white text (4.5:1 ratio enforced)

Implementation Notes

Embedded Css Architecture

BEM naming convention scoped to .paywall-modal context to prevent leakage. CSS variables used for easy theming.

Component Organization

Modular internal structure (Header, Body, PlanSelector, Footer) allowing for easy content swapping based on variant.

Responsive Design

Uses media queries to switch between centered modal (desktop) and bottom sheet (mobile).

Accessibility Compliance

Includes semantic buttons and proper landmark roles.

Browser Support

Supports all modern browsers. Flexbox and Grid used for layout.

Usage Guidelines

When To Use

When a user attempts to access a locked feature, exceeds a free tier limit, or navigates to 'Subscription' settings.

Content Guidelines

Title should be action-oriented ('Unlock', 'Upgrade'). Benefits should be concise bullet points.

Placement Rules

Always displayed as a top-level overlay with z-index > 1000.

Customization Options

  • Variant: 'Feature Lock' - specific icon/text for the locked feature
  • Variant: 'Limit Reached' - emphasizes capacity upgrade
  • State: 'Processing' - disables inputs and shows spinner on CTA

Testing Recommendations

Browser Testing

Verify backdrop blur support in Firefox/Safari.

Device Testing

Test on iPhone SE (small screen) to ensure scrolling works within the modal body.

Accessibility Testing

Verify focus trap logic (javascript required, but visual states provided).

Performance Testing

Check animation frame rate during modal entry.
