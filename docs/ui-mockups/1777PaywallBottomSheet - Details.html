Component Information

Component Id

ORG-MON-001

Component Name

PaywallBottomSheet

Component Type

organism

Description

A conversion-focused modal component displayed when users encounter premium-gated features or limits. It handles the presentation of benefits, pricing, and purchase actions.

Design System Alignment

Utilizes specific 'Premium' color tokens (Amber/Gold) distinct from the primary app theme to signal exclusivity, while maintaining standard typography and spacing scales.

Design Tokens Used

--color-premium-gradient
--color-premium-500
--color-neutral-900
--font-family-secondary
--radius-xl
--shadow-lg

Responsive Specifications

Mobile Adaptations

  • Fixed to bottom of screen
  • Full width
  • Slide up animation
  • Close button top-right within safe area

Tablet Adaptations

  • Centered modal dialog
  • Fixed max-width (480px)
  • Fade/Scale animation
  • Backdrop click to dismiss enabled

Desktop Enhancements

  • Consistent with tablet dialog behavior
  • Hover states on buttons active

Accessibility Features

Keyboard Support

Focus trap within modal, Escape to close

Screen Reader Support

Role='dialog', aria-modal='true', aria-labelledby='modal-title'

Focus Management

Initial focus on Upgrade button or Close button depending on context

Aria Attributes

  • aria-busy='true' during purchase
  • aria-label on close button

Color Contrast

White text on Premium Gradient meets 4.5:1 ratio

Implementation Notes

Embedded Css Architecture

BEM naming convention used for all component classes

Component Organization

Showcase grid used to display variants side-by-side

Responsive Design

Media queries handle the structural shift from Bottom Sheet to Dialog

Accessibility Compliance

Semantic HTML structure with proper ARIA roles

Browser Support

Works in all modern browsers, flexbox/grid used for layout

Usage Guidelines

When To Use

When a free user attempts to access a paid feature or hits a usage limit

Content Guidelines

Title should address the specific trigger (e.g., 'Unlock Unlimited Books'). Benefits should focus on value.

Placement Rules

Always overlay on top of current content with a backdrop

Customization Options

  • .paywall-sheet--lock modifier for icon-heavy layout
  • Data attributes for pricing dynamic insertion

Testing Recommendations

Browser Testing

Verify layout on Mobile (375px) vs Tablet (768px)

Device Testing

Test touch targets on actual mobile device

Accessibility Testing

  • Verify tab order cycles within modal
  • Verify screen reader announces title immediately on open

Performance Testing

Check animation smoothness on low-end devices
