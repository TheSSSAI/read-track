Component Information

Component Id

Component Name

DashboardHeader

Component Type

organism

Description

Primary top navigation and status area for the dashboard screen. Displays user greeting, current date, streak status, and quick actions.

Design System Alignment

Implements H1 typography for greetings, secondary colors for streak indicators, and standard spacing tokens.

Design Tokens Used

--color-primary-600
--color-secondary-500
--h1-size
--space-4
--color-gray-900

Responsive Specifications

Mobile Adaptations

  • Stacked layout: Date top left, Actions top right, Greeting below
  • Sticky positioning with scroll effects
  • Reduced padding

Tablet Adaptations

  • Row layout: Greeting left, Actions right
  • Increased padding (32px)
  • Date integrated into greeting block

Desktop Enhancements

  • Max-width constraints alignment
  • Additional hover states on actions

Accessibility Features

Keyboard Support

Logical tab order through actions

Screen Reader Support

Role='banner', aria-label on icon buttons

Focus Management

Visible focus rings on interactive elements

Aria Attributes

  • aria-label='Notifications'
  • aria-label='User Profile'
  • aria-current='date'

Color Contrast

Text and icons meet 4.5:1 ratio

Usage Guidelines

When To Use

Greeting should be personalized. Date should be current.

Placement Rules

  • Include/exclude .streak-badge based on user state
