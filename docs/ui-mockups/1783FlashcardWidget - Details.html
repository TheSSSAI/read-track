Description

An interactive, double-sided card component designed for vocabulary learning. It features a 3D flip animation to toggle between the prompt (word) and the answer (definition/example), maintaining aspect ratio and accessibility focus states.

Design System Alignment

Utilizes the card styling patterns (shadows, border-radius), typography scales (H2 for words, Body for definitions), and primary color tokens for accents.

Design Tokens Used

--color-primary-600
--color-surface
--radius-xl
--shadow-md
--font-secondary

Responsive Specifications

Mobile Adaptations

  • Aspect ratio shifts to 3/4 for better vertical space usage
  • Font size reduction for main word
  • Reduced padding on container edges

Tablet Adaptations

  • Maintain 4/5 aspect ratio
  • Center alignment in grid or modal

Desktop Enhancements

  • Hover effects for interaction affordance
  • Max-width constraint of 400px

Accessibility Features

Keyboard Support

Uses hidden checkbox to allow Space/Enter to flip via label association

Screen Reader Support

aria-live regions can be added, but semantic H2/P tags are used for content structure

Focus Management

Focus ring is projected onto the card container when the hidden checkbox receives focus

Aria Attributes

  • aria-label='Flashcard'
  • role='button'

Color Contrast

Text colors checked against gray-900 and gray-500 for AA compliance

Implementation Notes

Embedded Css Architecture

BEM naming (flashcard__face, flashcard__word) styled within document head

Component Organization

Self-contained widget relying on a hidden checkbox state pattern to demonstrate interactivity without JS

Responsive Design

Container query-like behavior via max-width and aspect-ratio

Accessibility Compliance

Semantic markup, clear focus indicators, high contrast text

Browser Support

Requires 3D transform support (modern browsers)

Usage Guidelines

When To Use

In vocabulary learning games or study modes

Content Guidelines

Keep the word short (1-3 words), definition concise. Example sentence provides context.

Placement Rules

Center on screen, typically accompanied by 'Know it' / 'Dont know it' action buttons below

Customization Options

  • Study Mode: Standard flip
  • Quiz Mode: Front only

Testing Recommendations

Browser Testing

Safari (iOS) for 3D transform glitches, Chrome, Firefox

Device Testing

Touch interaction speed on mobile devices

Accessibility Testing

Ensure screen reader reads the visible side content

Performance Testing

Smoothness of the 600ms flip animation
