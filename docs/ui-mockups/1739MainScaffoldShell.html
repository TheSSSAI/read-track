Component Variations

Variant Name: "Mobile Authenticated"

Standard mobile layout. The Navigation Rail is hidden via CSS, and the Bottom Navigation Bar is visible. The content stacks vertically.

Variant Name: "Tablet/Desktop Authenticated"

Responsive layout for screens > 600px. The CSS Grid/Flex direction changes to row. The Bottom Navigation Bar is hidden, and the vertical Navigation Rail appears on the left.

Variant Name: "Offline Mode"

Demonstrated in the Tablet view above. Adds the .scaffold--offline class to the root element, which triggers the visibility of the high-contrast offline banner at the top of the stack.
