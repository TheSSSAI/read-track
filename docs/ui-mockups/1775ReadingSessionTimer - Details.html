Description

A comprehensive interactive timer interface for tracking reading sessions. Includes visual time display, book context, and playback controls (start, pause, stop).

Design System Alignment

Utilizes primary indigo palette for active states, fluid typography for time display, and standard spacing tokens. Implements circular progress patterns consistent with dashboard widgets.

Usage Guidelines

When To Use

On the 'Log Reading Session' screen when the user opts for timed tracking.

Content Guidelines

Must display the currently selected book. Time format should be HH:MM:SS.

Placement Rules

Center of screen or prominent card within the view.

Customization Options

  • .reading-timer--paused for suspended state visual cues
