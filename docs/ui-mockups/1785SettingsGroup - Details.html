Component Information

Component Id

ORG-SET-001

Component Name

SettingsGroup

Component Type

organism

Description

A grouped collection of interactive setting list tiles used to organize user preferences, navigation, and actions within the Settings screen.

Design System Alignment

Utilizes standard list tile spacing, semantic colors for destructive actions, and consistent typography for headers and labels.

Design Tokens Used

--color-primary-600
--color-gray-100
--color-white
--radius-lg
--font-weight-medium

Responsive Specifications

Mobile Adaptations

  • Full width container
  • Tall touch targets (min 56px height)
  • Large toggle switches for easy tapping

Tablet Adaptations

  • Constrained width (max 600px)
  • Standardized margins

Desktop Enhancements

  • Hover highlighting
  • Consistent spacing within settings layout

Accessibility Features

Keyboard Support

Full tab navigation through list items and switches

Screen Reader Support

Role='group', proper labeling for switches

Focus Management

Visible outline on focus for tiles and switches

Aria Attributes

  • role='switch'
  • aria-checked
  • aria-labelledby

Color Contrast

Text and icon colors meet AA standards

Implementation Notes

Embedded Css Architecture

BEM naming convention used for all classes

Component Organization

Separated into Group Shell, Tile Item, and Switch Control

Responsive Design

Fluid width with max-width constraints on larger screens

Accessibility Compliance

Semantic button elements used for interactivity

Usage Guidelines

When To Use

On SettingsScreen or ProfileScreen to group related options

Content Guidelines

Keep labels concise. Use icons to improve scanability.

Placement Rules

Stack groups vertically with spacing between them

Customization Options

  • Add .settings-tile--destructive for danger actions
  • Use span.settings-tile__value for status text

Testing Recommendations

Browser Testing

Device Testing

Mobile and Tablet viewports

Accessibility Testing
