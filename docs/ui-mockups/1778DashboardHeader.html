Implementation Notes

  • Responsive Strategy: Uses a flex-direction: column approach for mobile to stack date and greeting, switching to flex-direction: row on tablets (min-width: 768px).
  • Scrolled State: The .dashboard-header--scrolled class applies a glassmorphism effect (backdrop-filter) and hides the large greeting to save screen real estate. In a Flutter implementation, this corresponds to a SliverAppBar.
  • Accessibility: The header uses role="banner". Interactive elements (Avatar, Icons) use semantic button tags with aria-label. The streak badge uses role="status".
  • Design System: Uses --color-primary-600 for focus states and --color-secondary-500 (Rose) for the streak badge as defined in the atomic design specs.
