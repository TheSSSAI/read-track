Component Name

Component Type

organism

Description

A visual representation of reading activity frequency over time, displaying daily intensity in a grid format similar to contribution graphs.

Design System Alignment

Utilizes the primary color scale for intensity levels, standard spacing tokens for grid gaps, and card styling from data display patterns.

Design Tokens Used

--color-primary-200
--color-primary-400
--color-primary-600
--color-primary-900
--color-gray-100
--radius-lg
--shadow-sm

Responsive Specifications

Mobile Adaptations

  • Horizontal scrolling container enables viewing full history
  • Day labels hidden to save horizontal space
  • Padding reduced to maximize data density

Tablet Adaptations

  • Full year view fits without scrolling
  • Labels fully visible
  • Standard padding restored

Desktop Enhancements

  • Hover tooltips fully interactive
  • Expanded width allows for up to 52 weeks display

Accessibility Features

Keyboard Support

Arrow keys to navigate grid (logical order), Enter/Space to activate details

Screen Reader Support

Role='grid', cells use aria-label containing date and activity count

Focus Management

High-contrast focus ring with Z-index elevation

Aria Attributes

  • aria-label='Reading activity heatmap'
  • aria-readonly='true'

Color Contrast

Intensity colors tested against white background, tooltip contrast > 7:1

Implementation Notes

Embedded Css Architecture

BEM naming (heatmap-card, heatmap-cell) with scoped CSS variables for colors

Component Organization

Self-contained card organism with internal layout handling

Responsive Design

CSS Grid auto-flow column for week handling + overflow-x: auto wrapper

Accessibility Compliance

Semantic structure using list or grid roles, not just divs

Usage Guidelines

When To Use

On Profile or Statistics screens to show consistency habits

Content Guidelines

Title should be descriptive (e.g., 'Reading Consistency')

Placement Rules

Full width of container, usually near top of stats page

Customization Options

  • Adjust --cell-size for tighter/looser density
  • Modify --heatmap-level-* vars for different themes

Testing Recommendations

Browser Testing

Check scroll behavior on mobile Safari/Chrome

Device Testing

Verify touch targets on cell interaction

Accessibility Testing

  • Verify tabbing sequence through days
  • Check Screen Reader announcement of data points

Performance Testing

Ensure rendering 365 div elements doesn't cause layout thrashing
