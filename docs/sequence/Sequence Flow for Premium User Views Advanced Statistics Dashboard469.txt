# 1 Overview

## 1.1 Diagram Id

SEQ-UJ-002

## 1.2 Name

Premium User Views Advanced Statistics Dashboard

## 1.3 Description

A user with a 'Premium' subscription navigates to the 'Insights' section of the application. The client requests advanced statistical data, which the backend computes or retrieves from pre-aggregated tables to ensure a fast response.

## 1.4 Type

🔹 UserJourney

## 1.5 Purpose

To deliver the 'Advanced Statistics and Insights' feature exclusive to Premium Users, as per REQ-STA-001.

## 1.6 Complexity

Medium

## 1.7 Priority

🔴 High

## 1.8 Frequency

OnDemand

## 1.9 Participants

- REPO-FE-MOBILE
- REPO-BE-HOST

## 1.10 Key Interactions

- A 'Premium User' taps on the 'Insights' tab in the mobile client.
- The client sends a GET /api/v1/statistics/advanced request to the backend.
- The backend API authorizes the request, ensuring the user has the 'premium_user' role from their JWT.
- The MOD-ENGAGEMENT service queries the database for aggregated data, such as reading streaks, pace trends, and activity by time of day.
- The backend returns a comprehensive DTO containing all the calculated statistics.
- The client receives the data and renders it using charts and other visual components.
- The client ensures the charts use color-blind accessible palettes.

## 1.11 Triggers

- A Premium User navigates to the statistics/insights screen.

## 1.12 Outcomes

- The user can view their detailed reading habits and trends.
- The value of the premium subscription is demonstrated to the user.

## 1.13 Business Rules

- This endpoint must be accessible only to users with a Premium subscription.
- Data should be retrieved from pre-calculated or efficiently indexed tables to meet performance NFRs.

## 1.14 Error Scenarios

- A 'Free User' attempts to access the endpoint and receives a 403 Forbidden error.
- The data aggregation query is slow, causing the request to time out.

## 1.15 Integration Points

*No items available*
