# 1 Overview

## 1.1 Diagram Id

SEQ-OP-001

## 1.2 Name

Production Deployment with Go-Live Checks

## 1.3 Description

A new version of the application is deployed to production via a CI/CD pipeline. The pipeline uses AWS CDK for infrastructure, runs automated end-to-end tests against the new deployment, and coordinates the app store release. Post-launch, an intensive monitoring phase ensures NFRs are met.

## 1.4 Type

🔹 OperationalFlow

## 1.5 Purpose

To ensure a reliable, repeatable, and safe process for releasing new software versions to end-users, as detailed in REQ-TRN-001.

## 1.6 Complexity

High

## 1.7 Priority

🚨 Critical

## 1.8 Frequency

OnDemand

## 1.9 Participants

- GitHub Actions
- AWS CDK
- REPO-BE-HOST
- REPO-FE-MOBILE
- Apple App Store / Google Play Store

## 1.10 Key Interactions

- Code merge triggers a GitHub Actions workflow.
- Workflow builds artifacts and executes AWS CDK to deploy infrastructure changes.
- A full suite of automated end-to-end tests are run against the newly deployed backend.
- If tests pass, mobile builds are submitted to app stores for review.
- Upon approval, the release is coordinated to go live.
- An intensive monitoring phase begins, tracking system health, P95 latency, and error rates for 72 hours against go-live success criteria.

## 1.11 Triggers

- Code is merged into the main branch.

## 1.12 Outcomes

- A new version of the application is successfully and safely deployed to production.
- Go-live success criteria are met (zero critical incidents, latency below 200ms).

## 1.13 Business Rules

- A deployment cannot proceed if automated tests fail.
- Go-live is only considered successful if specific performance and stability metrics are met.

## 1.14 Error Scenarios

- The CDK deployment fails.
- End-to-end tests fail against the production environment.
- A critical bug is discovered post-launch.

## 1.15 Integration Points

- AWS APIs
- Apple App Store Connect API
- Google Play Console API

The process leverages Infrastructure as Code (IaC) via AWS CDK for backend deployment, executes a comprehensive E2E test suite against the live environment, and coordinates mobile app store releases.
