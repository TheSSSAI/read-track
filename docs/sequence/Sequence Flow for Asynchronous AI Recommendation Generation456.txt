# 1 Overview

## 1.1 Diagram Id

SEQ-IF-001

## 1.2 Name

Asynchronous AI Recommendation Generation

## 1.3 Description

The system generates personalized book recommendations using Retrieval-Augmented Generation (RAG). The backend retrieves relevant user context via a k-NN similarity search on a vector store (OpenSearch), constructs a detailed prompt, calls the OpenAI API asynchronously, parses the response, and stores the structured recommendations.

## 1.4 Type

🔹 IntegrationFlow

## 1.5 Purpose

To provide a high-value, personalized feature for users, as specified in REQ-AIS-001.

## 1.6 Complexity

Critical

## 1.7 Priority

🔴 High

## 1.8 Frequency

OnDemand

## 1.9 Participants

- REPO-FE-MOBILE
- REPO-BE-HOST
- Amazon OpenSearch Serverless
- OpenAI GPT-4 API

## 1.10 Key Interactions

- User requests a new recommendation.
- Client sends request to the backend, which initiates an async job and returns a job ID.
- The job performs a k-NN similarity search in Amazon OpenSearch to find relevant context (past readings, goals, feedback).
- The job constructs a detailed prompt with the retrieved context.
- A rate-limited HTTP client calls the OpenAI GPT-4 API.
- The job parses the LLM's text response into structured recommendation data.
- The recommendations are saved to the database.
- The client polls a status endpoint with the job ID and retrieves the recommendations when ready.

## 1.11 Triggers

- User explicitly requests a recommendation.
- A scheduled trigger generates new recommendations proactively.

## 1.12 Outcomes

- Personalized, AI-powered book recommendations are available to the user.

## 1.13 Business Rules

- Calls to the LLM API must be rate-limited to control costs.
- User feedback on recommendations must be stored and vectorized to refine future context retrieval.

## 1.14 Error Scenarios

- The OpenAI API is unavailable or returns an error.
- The LLM response is in an unexpected format and cannot be parsed.
- The vector search in OpenSearch fails.

## 1.15 Integration Points

- OpenAI GPT-4 API (SI-003)
- Amazon OpenSearch Serverless

# 2.0 Details

## 2.1 Diagram Id

SEQ-IF-001

## 2.2 Name

Implementation-Ready: Asynchronous AI Recommendation Generation (RAG)

## 2.3 Description

A detailed technical sequence for generating personalized book recommendations asynchronously. This flow utilizes a Retrieval-Augmented Generation (RAG) pattern where a background job, initiated by a user request, queries a vector database (Amazon OpenSearch) for contextual user data, constructs a rich prompt, invokes the OpenAI GPT-4 API via a resilient client, parses the response, and persists the structured recommendations. The client polls for the result using a job-based status-check pattern.
